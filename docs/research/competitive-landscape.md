# Rackline Competitive Landscape

**Verdict:** Almost no competitor owns the full “garage → manufacturer WMS” arc with floor-map ops, Promise leave-by, Cloudflare edge, and maker narrative together. Closest pressure: **Katana** (makers → MRP), **Craftybase/Stocksmith** (maker COGS), **ShipHero/Packiyo/Logiwa** (real WMS), **Prediko/Inventory Planner** (AI replenishment).

**Strategic wedge:** Own warehouse execution for makers who manufacture — Garage Mode → full floor — not enterprise 3PL and not MRP-only.

**Brand collision:** [rackline.com](https://www.rackline.com/) is a UK physical shelving manufacturer. Always brand as **Rackline WMS** in titles/meta; pursue a distinct software domain before serious SEO spend.

---

## Where Rackline wins uniquely

- **Garage Mode → full warehouse** as a product story (Category A stops at recipes/MRP; Category C assumes a warehouse)
- **2D/3D floor maps + scan-to-move** as primary UX (bin lists dominate elsewhere)
- **Promise leave-by + Live day board + Runway stockout** operational loop
- **Cloudflare-native** (Workers/D1/R2) — edge cost and ops story for technical founders
- **Makers narrative without ShipHero ACV** (~$2k/mo) or enterprise SI tax

## Where Rackline is behind for maker conversion

1. QBO/Xero COGS + journal sync
2. Multi-channel OMS beyond Shopify (Amazon/Etsy/Walmart/Faire)
3. Crowdfunding / BackerKit import
4. AI demand / replenishment polish (Runway→PO)
5. Mature barcode hardware packaging
6. Deep MRP schedule UI
7. Returns portal (partner first)
8. EDI / wholesale ASN depth
9. 3PL billing rate-card polish
10. Shopify App Store distribution + Stocky-replacement messaging

## Steal-from cheat sheet

- **Steal makers from:** Craftybase/Stocksmith, Katana Free→Core, Zoho, SOS
- **Steal shipping-only Shopify from:** ShipStation Standard, Ordoro, Pirate Ship graduates
- **Steal Stocky refugees from:** Alfred/Prediko *plus* real warehouse promise
- **Avoid head-on ACV wars with:** ShipHero, Logiwa, Extensiv, Deposco until Garage/map/Promise are marketed
- **Never pitch against:** Manhattan / Blue Yonder / SAP EWM / Oracle — use as contrast

## Roadmap must-haves (competitive)

**Tier 1 — maker conversion:** QBO/Xero; Shopify App + Stocky replacement; crowdfunding CSV import; kit tier templates; Wave A/B landing pages

**Tier 2 — vs Katana/Cin7:** Etsy/Faire; light schedule; Runway→PO; recall/genealogy report; hardware kits docs

**Tier 3 — light 3PL & upmarket:** Client portal; billing rate cards; EDI lite; returns partner
